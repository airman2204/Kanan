# Dominios: Estrategia de Crecimiento x4 para Kanan

Para multiplicar un negocio de servicios a domicilio por 4, no necesitas multiplicar tu esfuerzo por 4; necesitas accionar simultáneamente las 4 palancas matemáticas del revenue:

```
Revenue = (Prospectos) x (% Conversión) x (Ticket Promedio) x (Frecuencia de Compra)
```

Si mejoramos moderadamente cada palanca, el efecto compuesto da más de 4x:
- +40% en prospectos (Meta Ads locales + Google Maps 4.9★)
- +30% en conversión (Wizard web rápido + Chat Bridge de WhatsApp + Scripts Show-up)
- +40% en ticket promedio (Vender combos: Sala + Colchón UV + Teflón)
- +50% en recurrencia (Automatizar el follow-up a 6 meses para volver a lavar)

`1.4 x 1.3 x 1.4 x 1.5 = 3.82x (Prácticamente 4x)`
